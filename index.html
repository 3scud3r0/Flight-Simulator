GamepadManche esquerdo / gatilhos / botões

Na pista: aumente a potência e puxe o manche ao atingir a velocidade de rotação. No Desafio, atravesse as argolas no sentido correto e ganhe pontos, combos e impulso automático por 3,5 s. Argolas perdidas zeram o combo. O gamepad usa manche esquerdo para rolagem e arfagem, manche direito horizontal para leme, RT/LT para potência, A para iniciar, B para trem, X para flaps, Y para câmera e Start para pausa.
